Web GIS / Labs / Lab 2
Lab 02 · 3 hours

District Explorer

Building a web map from a shapefile. Pick a province, watch the map redraw with only its districts, shaded by population, with each district's attributes one click away.

Download handout (PDF) Reference map View code

What you will build

A working web map of Pakistan's districts, published at a public URL. You will also produce a short measurement report comparing file sizes, load times and computed areas, using your own numbers rather than the figures quoted in the lecture.

Learning outcomes

  1. Convert a shapefile to GeoJSON and control its size.
  2. Explain the effect of coordinate precision and simplification on file size, and choose values appropriate to a map's scale.
  3. Read a GeoJSON file as text and identify its structure and its errors.
  4. Request a file from JavaScript and inspect it in the browser console.
  5. Draw, style, classify and filter a vector layer with Leaflet.
  6. Connect an HTML control to a map through an event listener.
  7. Measure the difference between an area computed in Web Mercator and one computed in a projected system.
  8. Publish a static site and read its network activity.

Parts and timing

Parts 1 to 7 are the core. Parts 8 and 9 are extensions. If you run short of time, complete Part 10 first so your work is published.

The data

The Pakistan Common Operational Dataset for administrative boundaries, published by OCHA on the Humanitarian Data Exchange and sourced from the World Food Programme. You need only the district layer (administrative level 2, 160 features). Download the prepared copy from LMS; its fields are already renamed to district, province, pop_2023 and area_km2.
